# 🤖 AI Lead & Inquiry Extractor

A lightweight Python automation tool designed for small businesses to automatically parse, structure, and prioritize incoming customer inquiries using Google's Gemini API.

## Features
- Extracts critical data points (Customer name, service requested, urgency level) from messy text messages or emails.
- Automatically suggests the next best action for the business owner.
- Easily integrates into CRM systems or chat workflows.
